# My GIS Agent

My GIS Agent is an AI assistant for QGIS.

## Vision

The assistant should help users:

- Create maps
- Load GIS data
- Run geoprocessing tools
- Explain GIS concepts
- Build workflows
- Automate repetitive GIS tasks

## Future Goals

- QGIS plugin
- AI chat interface
- Spatial analysis assistance
- MCP integration
- Automated cartography

## Status

Early development.
